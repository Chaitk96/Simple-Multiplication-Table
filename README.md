Multiplication Table Generator

A simple web project that generates a multiplication table based on the number entered by the user.

Features

  1) Enter any number

  2) Generate its multiplication table

  3) Displays the table from 1 to 10

  4) Simple and beginner-friendly interface

Technologies Used

  1) HTML

  2) CSS

  3) JavaScript

How It Works

  1) Enter a number in the input field.

  2) Click the Generate Table button.

  3) JavaScript calculates the multiplication table.

  4) The results are displayed on the webpage.
